# Sheet Editor

Sheet Editor 可以从云资料打开 XLSX、XLS 和 CSV，并保存编辑副本或导出 XLSX。

## 建议流程

1. 从私人云资料打开原文件。
2. 完成修改后先保存 Sheet 编辑副本。
3. 需要交换文件时再导出 XLSX。

复杂公式、图表、宏和特殊格式可能无法完整保留。重要文件请保留原始副本，并在导出后重新核对。
