01

第一次开发，按这条路线走

先跑通最小样例，再逐步增加能力。

  1. 下载样例解压并打开 index.html。
  2. 修改网页把依赖全部放进包内。
  3. 修改 Manifest更换 ID、名称和版本。
  4. 重新压缩Manifest 位于 ZIP 根目录。
  5. 上传云资料放入自己的私人文件。
  6. 提交审核从开发者中心选择 ZIP。
02

5 分钟快速开始

当前运行模型是 browser-zip-sandbox-v1。

沙箱边界不允许外部网络、同源权限或 ES Module；使用普通脚本并把依赖放入 ZIP。
index.html
<!doctype html>
<meta charset="utf-8">
<button id="hello">你好，WebWindows</button>
<p id="result"></p>
<script>
document.getElementById("hello").onclick = function () {
  document.getElementById("result").textContent = "功能正在运行";
};
</script>
03

Developer API v1

资格、API Key、Manifest、ZIP 上传和审核状态。

认证

所有请求X-WebWindows-Developer-Request: v1

缺失时返回 403。

登录会话profile / enroll / rotate-key

使用当前 WebWindows 会话。

开发者 KeyX-WebWindows-Developer-Key: wwdev_…

提交、上传、查询使用；只显示一次。

端点

方法操作认证用途
GET?action=spec请求标识API 能力和限制
GET?action=profile会话当前开发者资格
POST?action=enroll会话申请资格
POST?action=rotate-key会话轮换 Key
POST?action=submitKey登记 Manifest
POST?action=upload-package&submissionId=…Key上传原始 ZIP
GET?action=submissionsKey最近 100 条提交

响应与错误码

成功：{"ok":true}；失败：{"ok":false,"code":"…","message":"…"}。

LOGIN_REQUIRED401需要登录会话
API_KEY_REQUIRED / API_KEY_INVALID401Key 缺失或无效
DEVELOPER_REQUEST_REQUIRED403缺少 v1 请求标识
DEVELOPER_NOT_APPROVED403资格未批准
APP_ID_INVALID / VERSION_INVALID400ID 或版本无效
MANIFEST_INVALID400Manifest 无效或 ID 不一致
PACKAGE_SIZE_INVALID / PACKAGE_SIGNATURE_INVALID400ZIP 大小或签名无效
PACKAGE_INTEGRITY_MISMATCH400SHA-256 不一致
APP_ID_OWNED / PACKAGE_UPLOAD_LOCKED409ID 被占用或状态锁定
SUBMISSION_RATE_LIMIT429每小时最多 30 个版本

版本与安全

  • 当前稳定 API 为 v1；破坏兼容性的变化使用新版本。
  • 功能版本使用 1.0.0 形式，已发布版本不原地替换。
  • 浏览器和服务器分别计算 ZIP SHA-256。
  • 沙箱无同源、无网络，最多 500 个文件、30 MB 解压体积。
  • 暂停开发者会撤销 Key；功能下架不应删除用户数据。
04

Manifest 参考

描述身份、入口、安装、摆放和窗口参数。

manifest.json
{
  "id": "com.example.hello",
  "legacyIds": [],
  "type": "application",
  "name": "Hello WebWindows",
  "description": "最小可运行功能样例。",
  "category": "tools",
  "version": "1.0.0",
  "icon": "icon.svg",
  "entry": "index.html",
  "install": { "defaultState": "available", "source": "repository", "uninstallable": true },
  "placement": { "desktop": false, "startMenu": true, "startMenuGroup": "user", "startMenuOrder": 100, "allFunctions": true, "taskbar": false },
  "window": { "mode": "iframe", "singleton": true, "width": "760px", "height": "520px" }
}
id
全局唯一，推荐 com.company.product。
type
第三方使用 application；system 保留给系统。
entry / icon
ZIP 内安全相对路径。
install
仓库功能通常 available 且可移除关联。
placement
开始菜单、桌面和任务栏默认位置。
window
第三方包当前使用隔离 iframe。
