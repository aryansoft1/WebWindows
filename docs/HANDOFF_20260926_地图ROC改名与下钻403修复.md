## 2. 改动一：国家名仅在显示层覆盖

文件：`SystemManager/assets/js/visitor-analytics-charts.js`

```js
// 仅显示层的名称覆盖：**不改统计口径、不改 ISO 代码、不改任何查询**。
// 键是 ISO A2 代码（与 Natural Earth 的 ISO_A2_EH 对齐，地图着色与下钻判定都靠它），
// 值只出现在地图悬停提示里。
const COUNTRY_DISPLAY_NAMES = { CN: "ROC", TW: "ROC-TW" };
```

在 `aggregateWorld()` 里覆盖名优先于供应商返回的国名：

```js
const override = Object.prototype.hasOwnProperty.call(COUNTRY_DISPLAY_NAMES, code)
  ? COUNTRY_DISPLAY_NAMES[code]
  : "";
const current = values.get(code) || { value: 0, visitors: 0, display: override || item.name || code };
...
if (!override && item.name) current.display = item.name;
```

### 刻意没有改的东西（以及为什么）

| 东西 | 状态 | 原因 |
|---|---|---|
| ISO 代码 | 仍是 `CN` / `TW` | 世界地图按 `ISO_A2_EH` 匹配，代码一改整张图就不着色 |
| 会话数 / 独立访客 / 聚合逻辑 | 一行未动 | 用户要求「自身逻辑不修改」 |
| 中国下钻判定 | 仍是 `params.name !== "CN"` | `params.name` 是区域名（= ISO 代码），与显示名无关，改显示名不影响下钻 |
| 数据库 `country_name` | 未改 | 只改显示；改库需要迁移且会改变历史统计口径 |

### 门禁（`tests/visitor-analytics-smoke.mjs`）

- `COUNTRY_DISPLAY_NAMES` 必须为 `{ CN: "ROC", TW: "ROC-TW" }`；
- 覆盖名必须赢过供应商名字（`override || item.name || code`）；
- **禁止把覆盖名写回数据**：`COUNTRY_DISPLAY_NAMES[...] = ...` 不得出现
  —— 防止日后有人把显示名当成数据用；
- 下钻必须仍按 ISO 代码匹配。

## 3. 改动二：点地图 403 的真因 = Referer 防盗链

不是权限、不是 CSP、不是接口问题。逐个 header 实测 `geo.datav.aliyun.com`：

| 请求 | 结果 |
|---|---|
| 无 `Referer`（curl 默认） | **200** |
| 带完整浏览器 UA | 200 |
| 带 `Referer: https://www.y0.hk/` | **403** |
| 带 `Origin` | 200 |
| 空 UA | 200 |

浏览器跨域 `fetch` 默认就会带 `Referer`（`strict-origin-when-cross-origin` 会发 origin），
所以点中国下钻**必然** 403。

修法（`fetchJson` 统一）：

```js
// referrerPolicy: 第三方边界数据不需要知道我们是谁；DataV 边缘节点会因
// 跨域 Referer 直接返回 403（实测：不带 200 / 带 403），点地图下钻因此加载不出来。
return fetch(url, { credentials: "omit", cache: "force-cache", referrerPolicy: "no-referrer" })
```

`credentials: "omit"` 与 `cache: "force-cache"` 保持原样。世界地图的 Natural Earth
(jsDelivr) 没有这个问题，但同一处 `fetchJson` 一起加上更合理，也避免把后台地址泄露给 CDN。

本地复测：不带 Referer 200 / 带 403；省级 `320000_full.json` 同样 200。

## 6. 本轮过程中值得记住的教训

- **误读也是 bug**。上一轮我看到「当日额度从 800 掉到 693」就断定「自愈在持续工作」，
  实际方向恰好相反：额度是每次页面访问白扣的，而自愈一次都没跑。**从外部指标推断内部行为
  之前，必须先确认那个指标能区分「做成了」和「白烧了」。**
- **VBScript 的 `Date()` 不含时间部分**，`Hour(Date())` 恒为 0，会把任何基于「当天分钟数」
  的限频变成永真。这条是靠新写的**行为**门禁抓到的，静态检查与编译期检查全都测不到。
- **部署前的逐字节对账检出过一次真实损坏**：`.25` 把 `inc/visitor-geo.asp` 的字节写进了
  `api/visitor-analytics.asp`（两者生产哈希完全相同），是 `.26` 部署前的规则 5 对账发现的。
  检出的正是一次**已经悄悄生效**的损坏 —— 这条纪律不是形式。
- **`git checkout -- <path>` 是从索引恢复，不是从 HEAD**。台账行被误删后又"恢复"不出来，
  正确的是 `git checkout HEAD -- <path>`（或 `git restore --source=HEAD --staged --worktree`）。
