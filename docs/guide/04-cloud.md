# 云资料

云资料分为公共区域和私人区域。未登录使用者可以读取允许访问的公共资料；私人资料需要正式登录。

## 打开文件

在支持的应用中选择“从云资料打开”，再选择文件。系统会按照扩展名寻找当前已安装的可用功能。

## 保存文件

保存入口只写入当前账户的私人资料。公共区域没有直接写入入口。当前单个文件最大 15 MB，同名覆盖会由服务端保留备份。

不要把 API Key、授权码或其他敏感信息放入公共资料。
