# Write Editor

Write Editor 第一阶段主要支持 DOCX。可以从云资料打开文档，保存编辑数据，并将结果另存为 DOCX。

旧版 DOC、复杂分页、文本框和部分高级样式可能不能完整转换。公共区域文件以只读方式打开，需要编辑时请保存副本到私人云资料。
