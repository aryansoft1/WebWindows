# 桌面与窗口

桌面用于放置已经启用并允许显示的功能。任务栏会显示当前打开的窗口。

## 常用操作

- 单击图标打开功能。
- 拖动标题栏移动窗口。
- 使用窗口按钮最小化、最大化或关闭。
- 在设置的“功能管理”中控制普通功能是否显示在桌面。

在手机或较窄的窗口中，桌面图标、任务栏和应用窗口会改用紧凑布局。
