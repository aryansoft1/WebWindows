# Slide Editor 演示文稿

## 功能用途

Slide Editor 可新建演示文稿或打开 PPTX，在可编辑画布中修改文字、字体、对齐、背景与图片；支持新增、复制、删除和排序幻灯片，选择常用版式、记录演讲者备注、放映，并保存或导出副本。

## 适用场景

快速制作日常演示、修改普通 PPTX、调整幻灯片顺序和版式、记录演讲者备注、放映预览，或在云资料之间保存副本时使用。

## 操作步骤

1. 打开 Slide Editor，从“文件”选择“新建演示文稿”或“从云资料打开”并选择 PPTX。
2. 在左侧缩略图选择页面；从“幻灯片”新增、复制、删除、上移或下移页面，并选择标题页、标题+内容、双栏、图片+文字或空白版式。
3. 在画布中编辑标题和正文，使用工具栏设置粗体、斜体、对齐、字号与背景色；需要图片时粘贴图片链接后确认。
4. 打开备注区输入演讲者备注；对兼容打开的 PPTX，可从“视图”在只读“原稿预览”和可编辑画布之间切换。
5. 从“放映”选择从头、从当前页或全屏放映，使用上一页/下一页检查顺序和版面后退出放映。
6. 选择“保存到云”“保存副本到云资料”或“导出 PPTX 到云”，再重新打开导出结果核对文字、图片和页面顺序。

## 操作结果

幻灯片可在窗口中逐页查看；另存成功后私人资料出现原文件或副本。

## 常见问题与权限提示

- 旧版 PPT 是二进制格式，当前浏览器端不负责转换。
- 复杂动画、音视频、字体和高级布局可能不能完整呈现。
- 复杂动画、音视频和高级母版仍需用完整演示软件复核，请勿只保留唯一原稿。
- 幻灯片、主题、放映、视图等菜单已接入繁中、English、日本語；步骤中的中文名称会随当前语言显示对应翻译。
