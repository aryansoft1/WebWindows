# 照相机与扫描

## 功能用途

从设备相机拍摄，或从云资料选择已有图片，完成文档裁边与增强、二维码识别、文字识别和翻译。文档可以整理为多页并保存为图片或 PDF；二维码结果只展示或等待确认，不会自动跳转。

## 适用场景

需要把纸质材料存入云资料、读取二维码文字、从图片提取文字，或在中日英内容之间辅助翻译时使用。

## 操作步骤

1. 打开“照相机与扫描”，点击启用相机并允许浏览器使用摄像头；没有相机时可选择“从云资料选择图片”。
2. 选择文档扫描、二维码、拍照翻译或场景翻译，再拍摄或载入一张清晰图片。
3. 文档模式中检查自动识别的边缘，按需旋转、调整滤镜并添加页面；二维码和翻译模式中核对识别文字后再继续。
4. 文档处理完成后选择保存图片或 PDF，并在系统文件对话框中确认云资料位置与文件名。

## 操作结果

文档模式会生成校正后的单页图片或多页 PDF；二维码模式会显示分类后的文本或链接；翻译模式会同时保留识别文本和译文。保存成功后可从云资料重新打开核对。

## 常见问题与权限提示

- 相机只会在主动点击启用后申请权限；若被拒绝，请在浏览器站点设置中重新允许，或改用云资料中的图片。
- 边缘检测、OCR、翻译和二维码识别取决于图片清晰度及浏览器能力；反光、倾斜或过小文字可能需要重新拍摄。
- 设备 API 不可用时，界面可能提示可选提供方；确认前应阅读数据用途，敏感图片不要发送到外部服务。
- 扫码登录后端当前未启用，相应按钮保持禁用；场景翻译是定时取帧与二维叠加，不代表 WebXR 或空间锚定能力。
- 二维码中的网址不会自动打开。请先检查域名、协议和内容，再自行确认是否访问。
