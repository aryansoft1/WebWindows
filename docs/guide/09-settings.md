# 设置

设置窗口目前包含语言与区域、桌面壁纸、显示设置、功能管理、蓝牙设备和使用向导入口。

显示缩放会影响桌面、窗口和任务栏的视觉尺寸。浏览器自身的页面缩放也会产生影响，遇到布局异常时可先恢复浏览器为 100%。

蓝牙能力依赖浏览器支持、HTTPS 环境和用户授权，并非所有设备都可用。
