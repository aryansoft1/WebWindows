# Dreama

Dreama 是 WebWindows 窗口中的网页浏览入口。输入网址或搜索词后，页面会尝试在 Dreama 窗口内显示。

许多网站会通过安全策略禁止被其他页面嵌入。遇到空白、拒绝连接或登录异常时，应改用设备上的完整浏览器访问。Dreama 目前不能替代完整浏览器。
