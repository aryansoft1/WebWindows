# 账户与登录

未登录时可以作为线下使用者进入桌面。登录后，WebWindows 会使用账户身份访问私人云资料，并尝试同步当前账户关联的功能。

## 同步状态

- **已同步**：服务器和当前浏览器的功能关联已完成同步。
- **离线待同步**：变更暂存在当前浏览器，联网后会继续尝试。
- **等待重试**：同步服务暂时不可用，系统会再次尝试。

不要在公共设备上保留登录状态。使用完毕后应从账户菜单注销。
