# WebWindows 概览

WebWindows 是在浏览器中运行的 Web 操作环境。它用桌面、开始菜单、任务栏、窗口和“功能”把网页能力组织成接近桌面系统的体验，同时可连接云资料、账户同步及受支持设备的宿主能力。

WebWindows 本身不是 Windows，也不会让网页自动获得操作系统的全部权限。普通浏览器版受到浏览器权限和兼容性限制；WebWindows Mobile / Android Host 可在明确授权后提供更多原生能力。

“桌讯”是 WebWindows 内置沟通与 AI 助手区域；其中“小讯”使用通用基础模型，并按需结合 WebWindows 产品知识回答。
