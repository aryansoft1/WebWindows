# 桌面、开始菜单与窗口

## 功能用途

桌面用于启动常用功能，开始菜单支持置顶常用入口；窗口可移动、缩放、最小化、最大化和关闭。任务栏悬停预览帮助辨认已打开窗口，工作空间则把不同场景的窗口分组，并在切换时保留应用状态。

## 适用场景

同时处理云资料与办公文档、从多个窗口中快速定位目标、按工作或生活场景分组窗口、批量整理桌面图标，或在手机上切换功能时使用。

## 操作步骤

1. 单击桌面图标启动功能；桌面没有目标时打开开始菜单搜索，并可将常用功能置顶。
2. 拖动标题栏移动窗口，拖动边缘调整大小；使用标题栏按钮最小化、最大化或关闭，窗口载入期间等待指针会自动恢复。
3. 将指针停在任务栏功能图标上查看实时窗口预览；单击预览或任务栏图标可恢复最小化窗口并切换焦点。
4. 单击任务栏的“任务视图”，或按 `Web 键 + Tab` 打开工作空间总览；选择“新建工作空间”并输入名称。
5. 在总览中切换、重命名或拖动工作空间调整顺序；把窗口卡片拖到另一个工作空间即可移动窗口。
6. 在桌面空白处拖出选择框，或用 `Ctrl/Cmd + 单击`、`Shift + 单击` 选择多个图标，再拖动其中一个项目整体移动所选项目。
7. 在窄屏设备上优先使用任务栏、任务视图和紧凑窗口布局，不要依赖精细的边缘拖动。

## 操作结果

每个打开的功能都能在任务栏找到；最小化后内容与工作空间归属保留，关闭后对应任务栏项消失。切换工作空间只改变当前显示的窗口组，不会重新启动应用。

## 常见问题与权限提示

- 窗口超出屏幕：尝试最大化，或把浏览器缩放恢复到 100% 后刷新。
- 拖动不顺畅：触屏请从标题栏空白处开始，避免按到按钮或嵌入页面。
- 删除含窗口的工作空间前会提示窗口将移动到哪个工作空间；确认前先核对目标。
- “任务视图 / Task View / タスクビュー”及工作空间相关按钮会随界面语言变化，图标和所在位置保持一致。
- “锁定、休眠、关闭、重新启动”只作用于 WebWindows 会话，不会控制设备电源。
