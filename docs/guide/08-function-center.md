# 功能中心

功能中心把功能分为“我的功能”“可添加”“系统功能”等类别。系统功能受到保护，普通功能可以关联或移除。

## 移除的含义

移除只解除当前使用者与功能的关联，不会删除服务器程序文件、云资料或个人数据。

可安装功能的发布和审核流程仍在持续验证。只有功能中心实际列出的项目才代表当前环境可提供。
