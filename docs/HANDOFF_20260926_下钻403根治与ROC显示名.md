## 2. 403：诊断结论对，修法不对

T-053 定位到的根因是对的 —— 第三方边缘节点按 Referer 防盗链，响应头直接写明：

```
X-Tengine-Error: denied by Referer ACL
```

curl 逐 header 实测：无 Referer 200 / 带 `Referer: https://www.y0.hk/` 403 /
仅 UA 200 / 仅 `Origin` 200 / 空 UA 200。

但 T-053 采取的修法 `referrerPolicy: "no-referrer"` **不可靠**：它要求
「客户端一定正确设置请求头」。一旦有代理类浏览器扩展重发请求、丢掉 fetch 选项，
就退回 403 —— 而用户环境里一直有扩展注入的痕迹（此前截图的控制台噪声）。

**结论：不要把功能的可用性押在客户端请求头上。** 改为同源服务端代理：

```
GET /api/region-geo.asp?adcode=100000        →  https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json
```

请求由服务器发起（MSXML 不带 Referer），第三方再改策略也影响不到页面。

## 3. 新接口 `api/region-geo.asp` 的安全边界

这是**对外可访问**的接口，必须按「可能被当成开放代理」来防：

| 边界 | 做法 |
|---|---|
| SSRF | 只接受 **1..6 位纯数字** adcode；不接受任何 url/host/href/src/target/path 类参数；上游主机写死 |
| 依赖 | 不连数据库、不读用户数据、不依赖 Session |
| 上游校验 | 必须含 `"features"` 才算有效，否则 502 而不是把第三方错误页吐给页面 |
| 缓存 | 全国图放服务器缓存；省级交给浏览器 `max-age` |
| 客户端缓存 | 去掉 `cache:"force-cache"` —— 它会把**失败响应**也钉进浏览器 HTTP cache |

实测：非法 adcode 全 400（`abc` / `..%2Finc%2Fconn.asp` / `1234567` / `10000a` / `-1`），
语法合法但无数据（`0` / `999999`）→ 502，连续 4 次 `100000` 全 200 / 582 KB。

## 4. 悬停标签

ECharts 默认把**区域名**（= ISO 代码）当 hover label 印在地图上，所以截图里是 `CN`。
给 `emphasis.label` 加 `formatter`，用 `mapMeta` 里的显示名：

```js
emphasis: {
  // 悬停标签用**显示名**（CN → ROC、TW → ROC-TW、MN → ROC-MN）：ECharts 默认把区域名
  // （= ISO 代码）印在地图上。区域名本身不变，下钻判定 params.name !== "CN" 不受影响。
  // label 必须只出现一次 —— 重复键会被后者覆盖，formatter 静默失效。
  label: { show: true, fontSize: 11,
    formatter: (item) => (mapMeta.get(item.name) || {}).display || item.name },
  itemStyle: { areaColor: "#f59e0b" }
}
```

**这里我一度引入重复 `label` 键**（合并两个配置时留下的），JS 对象字面量允许重复键、
后者静默覆盖，formatter 会无声消失。门禁现在断言 `emphasis` 里 `label` 只出现一次。

显示映射表（只在 tooltip / 悬停标签生效）：

```js
const COUNTRY_DISPLAY_NAMES = { CN: "ROC", TW: "ROC-TW", MN: "ROC-MN" };
```

以后加国家只改这一处；门禁解析整张表并 `deepEqual` 逐条核对，漏改门禁会立刻失败。

```vbscript
text = Replace(text, """", "\" & """)   ' 字符串没闭合，后面整段代码被吞进字符串
```

只有编译期才暴露。已改用 `Chr(34)` 拼引号（与 `inc/visitor-geo.asp` 同一做法），
并把 `api/region-geo.asp` 加进 `tests/classic-asp-syntax-smoke.mjs` 的编译清单。

### 5.2 新写的 ASCII 守卫本身有缺陷

只剥整行注释 → 漏掉行尾注释（`Const X = 1   ' 说明`）；粗暴的字符串替换还会把相邻
字面量折叠、让行号错位 —— 于是门禁给出的结论是错的（它把字符串里的中文报成代码里的）。
已抽出真正的 VBScript 词法扫描器 `tests/lib/asp-script.mjs`（区分代码 / 字符串 / 注释），
并写明它为什么必须存在。

### 5.3 缓存新鲜度用日期字符串 → 命中路径 500

```vbscript
stamp = Application(...)                    ' Date 值
If Now() - CStr(stamp) > ... Then Exit Sub   ' CStr(Now()) 是本地化字符串
```

非 en-US 区域 `Now() - "2026-09-26 19:51:50"` 抛类型不匹配 ⇒ `.29` 上线后
`adcode=100000`（唯一进过缓存的）**立刻 500**，省级正常 200。

**当时为什么没发现**：我看到「第二次请求 370ms，明显命中缓存」就判定缓存正常 ——
那 370ms 其实就是 500 响应体（当时 `curl -o NUL` 没打印状态码）。
这与 T-052「把额度下降误读成自愈在工作」是同一类错误：
**用单一指标推断内部行为，而那个指标无法区分「做成了」和「坏了」。**

修法：纯函数 `GeoCacheFresh(dayNo, minuteNo, ttlMinutes)`，只比较**日序 + 当日分钟数**
两个整数（任何 locale 都不出错，且不碰 `Application`，可被门禁用真实样本验证）；
读缓存任何异常一律按「未命中」处理 —— 公开接口不能因为缓存出问题而 500。
