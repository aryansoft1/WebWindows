# 5 分钟开始使用 WebWindows

## 功能用途

WebWindows 是运行在浏览器中的桌面工作空间。桌面放常用入口，开始菜单汇总全部功能，任务栏负责切换窗口，“认识我”和“使用向导”负责介绍产品与具体操作。

## 适用场景

第一次进入系统、换到新设备、找不到某个功能，或需要确认某项能力是否已经可用时使用。

## 操作步骤

1. 打开 WebWindows，等待任务栏头像从“正在确认登录状态”变为当前使用者。
2. 单击桌面图标，或单击左下角开始按钮后选择一个功能。
3. 同时打开两个功能，再用任务栏图标在窗口之间切换。
4. 从开始菜单打开“使用向导”，在顶部搜索框输入问题；按 `Ctrl+K` 可直接聚焦搜索框。

## 操作结果

目标功能会在 WebWindows 窗口中打开，任务栏出现对应图标；向导会保留当前主题在地址参数中，便于复制入口。

## 常见问题与权限提示

- 桌面图标因账户、安装状态和版本不同而变化，以开始菜单和功能中心实际显示为准。
- 首次访问某些功能需要登录、联网或浏览器授权；拒绝后可刷新并在浏览器站点权限中重新允许。
- 若界面一直显示“正在确认登录状态”，先检查网络，再刷新一次。
