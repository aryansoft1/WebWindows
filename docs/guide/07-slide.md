# Slide Editor

当前版本主要用于打开和查看 PPTX、切换幻灯片，并将原文件或副本保存到私人云资料。

旧版 PPT 是二进制格式，当前不会在浏览器中转换。复杂动画、音视频和高级排版可能无法完整呈现；目前不应把 Slide Editor 当作完整演示文稿编辑器。
