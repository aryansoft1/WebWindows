# WebWindows Cursor Manager

`assets/js/cursor-themes.js` owns cursor theme selection, persistence (`localStorage` key `webwindows.cursor.theme`), asset paths, hotspots, CSS tokens, and the page-wide cursor contract. The default theme is Dreama. Classic, Soft, Dark Pro, and Mono use the same 13 image states. Directional tokens map the eight resize edges and corners to the four resize images.

The manager installs a default cursor on `html`, `body`, and every body descendant. Semantic rules then cover links, buttons, text fields, disabled and busy controls, draggable elements, window title bars, and resize handles. `data-ww-cursor="state"` is the interface for an interaction state that cannot be inferred from HTML semantics. Existing CSS can set `--ww-cursor-state: var(--ww-cursor-link)` (or another token) so the manager's enforced cursor rule honors it. Business modules must use this attribute or token; they must not assign native cursor keywords directly. The manager strips inline cursor declarations added by legacy or third-party code and preserves a recognized state on non-semantic elements. New DOM nodes inherit the rules without component-specific initialization.

The manager installs the same stylesheet in same-origin iframes and in Shadow DOM roots created after initialization, including closed roots through `attachShadow`. Existing open roots are discovered at startup. A closed root created before the manager loads is inaccessible. Cross-origin and sandboxed opaque-origin iframe contents are inaccessible to page JavaScript; `WebWindows.cursor.crossOriginFrameCount` records observed frames with this limitation. The iframe element itself still receives the WebWindows cursor. Native cursor keywords remain only as resource-load fallbacks inside manager-generated cursor values or token fallbacks on standalone pages.

The audit for this change covered CSS and Vue style declarations, HTML inline styles, JS `style.cursor`/`cssText`, generated window resize and drag paths, bundled Vue widgets, same-origin iframe pages, third-party overrides, and Shadow DOM. Runtime selector ownership is centralized in the manager; legacy CSS declarations now reference tokens. The changed standalone iframe pages can still use native fallback when opened outside WebWindows because no manager tokens exist there.
