# 5 分钟开始使用 WebWindows

## 功能用途

WebWindows 是运行在浏览器中的桌面工作空间。桌面提供常用入口，开始菜单汇总已注册功能，任务栏管理已打开窗口；任务视图可按工作空间整理窗口，“认识我”介绍产品，“使用向导”提供逐项操作说明和搜索。

## 适用场景

第一次进入系统、换到新设备、找不到某个功能，或需要确认某项能力是否已经可用时使用。

## 操作步骤

1. 打开 WebWindows，等桌面和任务栏状态加载完成；头像显示访客时仍可浏览公开功能。
2. 单击桌面上的功能图标；若没有该图标，打开左下角开始菜单，在搜索框输入功能名称并从结果中选择。
3. 再打开一个功能，观察任务栏出现的窗口项；单击不同任务栏项切换窗口，悬停可查看窗口预览。
4. 单击任务栏“任务视图”按场景整理窗口；要新建工作空间、移动窗口或调整顺序，打开“工作空间总览”。
5. 从开始菜单打开“使用向导”，在顶部搜索框输入功能名或问题；按 `Ctrl+K` 可聚焦搜索，点左侧目录可阅读完整步骤。
6. 在窄屏设备上从目录按钮展开章节列表，选择章节后向下滚动阅读步骤和常见问题。

## 操作结果

目标功能会在 WebWindows 窗口中打开，并出现在任务栏或当前工作空间；向导显示对应章节、图片说明、操作步骤和限制。

## 常见问题与权限提示

- 桌面图标因账户、安装状态和版本不同而变化，以开始菜单和功能中心实际显示为准。
- 首次访问某些功能需要登录、联网或浏览器授权；拒绝后可刷新并在浏览器站点权限中重新允许。
- 若界面一直显示“正在确认登录状态”，先检查网络，再刷新一次。
- 目录中的功能取决于当前版本、账户关联和安装状态；搜索不到时到“功能中心”检查该功能是否可添加。
- 不同语言下按钮名称会翻译，图标和所在位置通常不变；本向导中的中文按钮名是识别操作的参考。
