# 问道地图与出行建议

## 功能用途

问道在 WebWindows 窗口内提供可交互地图：搜索地点、查找附近设施、选择起点和终点规划路线、查看距离与费用，开始导航后持续更新位置与剩余里程，还可以把路线摘要交给桌讯生成出行建议。地面、航班和公共交通三个标签页分别对应陆路路线、航班查询和公交线路。

## 适用场景

出差或旅行前确认路线与换乘、查找目的地附近的餐厅或停车场、记录航班状态，或希望由 AI 汇总一次出行注意事项时使用。

## 操作步骤

1. 打开问道，允许定位或手动在地图上选择起点和终点，也可以用搜索框直接查找地名。
2. 选择驾车、公交、步行或骑行方式后点“开始规划”，查看路线步骤、距离、时长和高速/IC 卡/现金费用。
3. 点“开始导航”进入连续导航；位置权限被拒绝时改为手动选点，页面不会伪造位置。
4. 路线就绪后点“问桌讯”，把路线摘要交给桌讯生成时间安排、换乘和费用提醒。

## 操作结果

获得可复核的路线步骤与费用明细；导航期间地图随位置更新。提交“问桌讯”后桌讯对话中会出现该次出行的建议草稿。

## 常见问题与权限提示

- 定位权限用于当前路线和导航，可以随时在浏览器中拒绝；拒绝后仍可手动选点规划。
- 社区地图服务不提供该方式的真实路线时会明确提示，不再绘制伪造的直线估算。
- 点击“问桌讯”只发送起点、终点、方式、距离、时长与费用，不发送坐标或连续移动轨迹。
- 费用与时刻可能含估算，出行前请以实际路况和官方票务为准。
