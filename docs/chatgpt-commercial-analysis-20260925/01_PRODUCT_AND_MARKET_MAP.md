# 1. 产品与市场地图

## 产品定义

WebWindows 是运行在浏览器中的模块化桌面环境。它用桌面、窗口、任务栏、
开始菜单、设置、文件系统、应用目录和开发者工具，把多个网页应用组织成一个
接近操作系统的统一工作空间。

当前更准确的产品类别是：

- 浏览器桌面 / Web OS shell；
- 可扩展的应用与功能运行平台；
- 带云文件、办公编辑、通信、出行和开发工具的个人工作空间；
- 可与 Android 外壳、原生桥接和设备能力结合的跨设备前端。

不应把当前版本描述为已经能替代 Windows、macOS 或完整 ChromeOS 的通用操作
系统。普通浏览器环境无法直接控制宿主设备的所有硬件与系统权限。

## 平台级能力

- 多窗口桌面：窗口打开、移动、缩放、最小化、最大化、任务栏及窗口缩略图。
- 应用目录与生命周期：系统应用、预装应用、安装状态、启动位置、文件关联。
- 文件与存储：云文件、设备/浏览器存储适配、文件选择器、资源打开协议。
- 设备能力抽象：Device API、Storage Adapter、声音、亮度、电池、网络、锁定及
  会话级电源操作；原生能力取决于可信外壳。
- 多语言和地区：中文、繁体中文、日语、英语相关字典与地区/时区处理。
- 开发者生态：Manifest、权限、SDK 沙箱、预览会话、能力代理、确定性构建、
  Developer Studio 与服务端包校验。
- 身份与管理：登录/会话、后台管理、功能目录、开发者平台、访客统计。
- 部署治理：版本化 FTP 清单、文件完整性、备份、上线前检查、入口依赖检查。

## 问道/问乡的当前产品边界

已实现并多轮上线验证的能力包括：

- 中国铁路查询及 12306 回落链路；
- 同城站名、候选车次、经停站和跨日时刻处理；
- 运行中/未发车/已通过车次分类与客户端当日快照；
- 地图跟随、车辆位置估算、车型图标；
- 海外 GTFS 多候选查询、缓存、错误归因和服务范围过滤；
- 海外只展示城际/干线铁路、高铁和长途大巴，排除地铁、捷运、通勤铁路和
  市内公交。

明确限制：

- 12306 不提供完整的当日已发车历史列表，也不直接提供可靠实时 GPS；当前
  “运行中位置”主要是时刻与路线插值估算。
- Transitland 不提供完整的新干线长期时刻数据，部分 trip 详情端点不稳定。
- Rome2Rio 只是未配置时完全惰性的预留插槽，不应宣传为现有商业能力。
- 用户已明确产品原则：没有长期可靠数据授权，就不把新干线/海外长途能力
  当作真实功能销售。

## 可供商业验证的客户群（假设，不是既有客户）

1. **中小企业/外贸团队的定制云工作台**  
   把文件、沟通、办公工具、企业入口和专用流程封装成品牌化浏览器桌面。

2. **学校、培训机构和轻量实验室**  
   用免安装工作台组织课程应用、文件、教程和受限开发环境。

3. **Web 应用开发者或垂直 SaaS 厂商**  
   借助应用 Manifest、权限、预览、文件关联和桌面壳，把已有 Web 应用变成
   “桌面应用套件”。

4. **中日跨境服务/旅游与出行场景**  
   利用多语言、地图、铁路和服务入口做面向特定路线或企业客户的工作台；
   但长期交通数据授权是商业化前置条件。

5. **私有部署/品牌化门户客户**  
   需要自有域名、应用目录、后台管理、内容和文件能力的组织。

这些方向需要通过客户访谈和付费试点筛选，不建议同时作为首发市场。
