# 隐私与安全

- 公共资料可能被其他使用者读取，不要存放个人或敏感信息。
- 私人资料依赖当前登录会话，离开公共设备前应注销。
- 不要把密码、API Key、邮箱授权码写入文档或功能包。
- 第三方功能可能有自己的数据处理方式，安装前应核对来源和说明。

功能包运行环境包含隔离和资源限制，但安全机制仍需与服务端审核流程共同工作。
