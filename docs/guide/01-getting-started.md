# 开始使用

WebWindows 是运行在浏览器中的 Web 工作空间。进入桌面后，可以从开始菜单打开系统功能和自己的功能。

## 先认识四个位置

1. **桌面**：放置常用功能图标。
2. **开始菜单**：查看系统功能、自己的功能和全部功能。
3. **任务栏**：切换已经打开的窗口。
4. **使用向导**：查找具体操作和功能边界。

## 打开和管理窗口

选择桌面或开始菜单中的功能即可打开窗口。窗口可以移动、缩放、最小化和关闭；窄屏设备会使用更适合触控的布局。

> 具体表现会受到浏览器、屏幕尺寸和当前网络状态影响。
