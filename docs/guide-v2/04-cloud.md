# 认识云资料与“此设备”

## 功能用途

云资料把文件位置分成公共资料、当前账户的私人资料和用户主动授权的“此设备”目录。公共资料可读，私人资料可由支持的应用保存，“此设备”目前只提供受控读取。

## 适用场景

查阅共享文件、编辑自己的文档、从已授权本地目录打开文件，或判断某个位置能否写入时使用。

## 操作步骤

1. 从开始菜单打开“云资料”；先看左侧位置栏，选择“公共区域”“私人文件”或“此设备”，并核对标题栏的当前位置。
2. 在文件区域使用搜索框按名称查找；选择名称、日期或大小排序，再选择列表、紧凑或图标视图，方便检查文件详情。
3. 双击文件打开默认应用；单击文件夹进入下一级，使用返回、上一级按钮或面包屑回到父目录。
4. 从操作菜单查看项目详情、下载、复制逻辑路径或使用打开方式；公共资料只读，保存编辑结果时切换至私人文件。
5. 要读取本机目录时切换到“此设备”，选择“添加本地位置”，并在系统选择器中只授权本次任务需要的文件夹。
6. 打开已授权位置后确认路径与状态；权限失效时重新授权原目录，不要为了方便授予整个磁盘。

## 操作结果

文件列表显示当前位置可访问的文件和文件夹；设备目录会带只读、可读写或权限失效状态，但公开 Storage v1 只承诺列出、读取和元数据能力。

## 常见问题与权限提示

- 私人文件入口不可用：先正式登录，并允许同源 Cookie。
- “此设备”不出现：浏览器或客户端不支持目录授权；使用普通上传/云资料替代。
- 设备位置授权失效：重新选择同一目录；系统不会静默扩大授权范围。
- 列表为空时先检查当前位置和搜索词，再清空搜索；公共区域为空不代表私人文件丢失。
- 按钮名称会随当前语言显示繁中、English 或日本語翻译；位置栏和文件夹层级的功能一致。
