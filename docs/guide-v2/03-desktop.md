# 桌面、开始菜单与窗口

## 功能用途

桌面用于启动常用功能，开始菜单支持置顶常用入口；窗口可移动、缩放、最小化、最大化和关闭。任务栏悬停预览帮助辨认已打开窗口，工作空间则把不同场景的窗口分组，并在切换时保留应用状态。

## 适用场景

同时处理云资料与办公文档、从多个窗口中快速定位目标、按工作或生活场景分组窗口、批量整理桌面图标，或在手机上切换功能时使用。

## 操作步骤

1. 单击桌面图标启动功能；桌面没有目标时打开开始菜单搜索，并将常用功能固定到开始菜单置顶区。
2. 拖动标题栏移动窗口，拖动边缘调整大小；标题栏按钮可最小化、最大化、还原或关闭窗口。
3. 将指针停在任务栏功能图标上，等待预览卡片显示窗口名称和内容；单击预览卡片恢复并激活该窗口。
4. 单击任务栏的“任务视图”，打开工作空间总览；选“新建工作空间”，输入名称并确认，工作空间会成为单独的窗口分组。
5. 按项目、日常事务等场景切换工作空间；在总览中重命名、拖动卡片排序，或把窗口卡片拖至目标工作空间以移动窗口。
6. 删除工作空间前查看确认框中的窗口数量和迁移目标；确认后窗口会被移至指定工作空间，不会随分组删除。
7. 在桌面空白处拖出选择框，或用 `Ctrl/Cmd + 单击`、`Shift + 单击` 选择多个图标，再拖动其中一个项目整体移动当前所选图标。
8. 在窄屏设备上使用任务栏与任务视图切换；窗口管理和工作空间总览在窄屏下仍可操作，但预览细节会收缩。

## 操作结果

工作空间是窗口的场景分组，不会复制或关闭应用；切换时隐藏非当前组并显示目标组，窗口状态继续保留。任务栏图标用于快速切换，悬停预览用于区分同一应用打开的多个窗口。

## 常见问题与权限提示

- 窗口超出屏幕：尝试最大化，或把浏览器缩放恢复到 100% 后刷新。
- 拖动不顺畅：触屏请从标题栏空白处开始，避免按到按钮或嵌入页面。
- 删除含窗口的工作空间前会提示窗口将移动到哪个工作空间；确认前先核对目标。
- “任务视图 / Task View / タスクビュー”及工作空间相关按钮会随界面语言变化，图标和所在位置保持一致。
- 工作空间切换不等于多个独立桌面账户，应用和会话仍属于同一个 WebWindows 使用者。
- “锁定、休眠、关闭、重新启动”只作用于 WebWindows 会话，不会控制设备电源。
